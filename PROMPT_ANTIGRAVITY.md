# Prompt untuk Antigravity — PAD Insight OKUS

Saya sedang mengembangkan proyek akademik bernama **PAD Insight OKUS**, aplikasi web untuk membantu monitoring target dan realisasi Pendapatan Asli Daerah Kabupaten Ogan Komering Ulu Selatan, dengan fokus awal Muaradua.

Folder ini sudah berisi starter code Flask + SQLite. Gunakan file yang ada sebagai dasar dan jangan membangun ulang semuanya tanpa alasan.

## Tugas tahap pertama
1. Baca `README.md`, `app.py`, semua template, dan CSS/JavaScript.
2. Periksa struktur proyek dan jalankan aplikasi secara lokal.
3. Identifikasi dan perbaiki error yang benar-benar ditemukan. Jangan hanya memberi saran; lakukan perubahan langsung pada file proyek.
4. Pastikan navigasi Dashboard, Data Pendapatan, Analisis PAD, Laporan, Pengguna, Pengaturan dan Keluar berjalan.
5. Uji tambah dan hapus data pendapatan, pencarian/filter, grafik, login demo, dan unduh CSV.
6. Pertahankan tampilan responsif untuk desktop dan mobile serta gaya visual biru/navy, kartu ringkasan, tabel dan grafik.
7. Jangan menghapus label `DATA SIMULASI`; jangan membuat klaim bahwa angka contoh adalah data resmi.
8. Setelah selesai, laporkan file yang diubah, fitur yang diuji, hasil pengujian, dan langkah menjalankan aplikasi.

## Tahap pengembangan setelah aplikasi berjalan
Lakukan secara bertahap dan tunggu konfirmasi sebelum perubahan besar:
- Tahap A: memperbaiki validasi input dan pengalaman pengguna.
- Tahap B: membuat autentikasi aman menggunakan password hashing dan proteksi formulir.
- Tahap C: menambah fitur edit data, filter periode, dan ekspor PDF.
- Tahap D: memperbaiki otorisasi berbasis peran (Administrator, Petugas, Pimpinan).
- Tahap E: menambah pengujian otomatis dan dokumentasi.

Jangan menghubungkan ke sistem pemerintah atau mengimpor data resmi tanpa sumber dan izin yang jelas. Jangan menaruh kredensial rahasia dalam source code.
